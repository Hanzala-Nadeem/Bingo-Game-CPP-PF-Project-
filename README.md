# Bingo Game - C++ PF Project

A console-based **Bingo game** implemented in C++ with a **color theme**, supporting **single-player** and **multiplayer** modes. This project demonstrates arrays, classes, randomization, and user input handling.

---

## Features

- **Single Player Mode** – Play against the computer.
- **Multiplayer Mode** – Play against another human player.
- **Color Theme** – Completed numbers highlighted in green.
- **Dynamic Board** – Users can choose number of rows and columns.
- **Automatic Marking** – Marks opponent’s card automatically.
- **Winning Condition** – First to complete a row or column wins.
- **High Score Tracking** – View previous game results from `score.txt`.
- **Console Display** – Clear and readable output.

---

## Gameplay Instructions

1. Run the program using a C++ compiler.
2. Choose a mode:
   - **Single Player** (`s`)
   - **Multiplayer** (`m`)
3. Enter player name(s) and board dimensions.
4. Take turns marking numbers:
   - Single player: You choose a number; computer marks it automatically.
   - Multiplayer: Both players take turns.
5. First to complete a row or column wins.
6. After the game, you can view the opponent’s card if desired.

---

## Requirements

- C++ Compiler (g++, clang, or Visual Studio)
- Windows console recommended for color support
